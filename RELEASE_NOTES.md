## MuhMeiMusic 1.4.6

A clean, ad-free Android music player. Local library, streaming, offline downloads, synced lyrics, and a queue that behaves.

### What's in this release

- Full app rebrand: name, launcher icon, splash and widget labels
- First-run welcome and support prompts removed — the app opens straight to your music
- Built-in update checker removed, so no nag on launch
- Playback verified on Android 15: MediaSession reports `PLAYING`, position advances, 48 kHz AudioTrack holds audio focus
- No ads, no trackers, no account needed for local music

### Install

1. Download `MuhMeiMusic.apk` below.
2. Allow "install unknown apps" for your browser or file manager when asked.
3. Open the file and install. If an older build is installed, uninstall it first (signatures differ).
