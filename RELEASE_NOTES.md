## Tarana 1.5.0

A clean, ad-free Android music player. Local library, streaming, offline downloads, synced lyrics, and a queue that behaves.

Tarana is a free and open source project, built on top of the open source Android music ecosystem.

### What's new in 1.5.0

- **New name: Tarana.** Launcher label, home header, widgets, share strings and settings all renamed.
- **"Tarana Wrap"** replaces the old year-in-music naming, including the share text.
- **Self-updating from this repository only.** The app checks this repo's latest GitHub release, compares it to the installed version, and if a newer one exists it downloads the APK and opens the Android installer directly — no browser, no redirects, no third-party download page.
- **About screen removed entirely** — no developer links, no support links, nothing in Settings or settings search. The Settings list ends at Supported Links.
- **Version display fixed** — the update screen now reports the real installed version.
- No ads, no trackers, no account needed for local music.

### Install

1. Download `Tarana.apk` below.
2. Allow "install unknown apps" for your browser or file manager when asked.
3. Open the file and install. If an older build signed with a different key is installed, uninstall it first.
