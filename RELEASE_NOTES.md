## MuhMeiMusic 1.4.7

A clean, ad-free Android music player. Local library, streaming, offline downloads, synced lyrics, and a queue that behaves.

### What's new

- **About screen removed entirely** — no developer links, no support links, no entry in Settings or settings search. The Settings list now ends at Supported Links.
- **Self-updates from this repository.** The built-in updater now reads this repo's latest GitHub release, shows its changelog, and downloads the attached APK. The "you'll be redirected to a site with ads" notice is gone — updates come straight from here.
- **Wrapped screen branding fixed** — the recap header and its share text now say MuhMeiMusic.
- **"From your taste by MuhMeiMusic"** replaces the old label on music-flow mixes.
- No ads, no trackers, no account needed for local music.

### Install

1. Download `MuhMeiMusic.apk` below.
2. Allow "install unknown apps" for your browser or file manager when asked.
3. Open the file and install. If an older build is installed, installing over it works only if it was signed with the same key — otherwise uninstall the old build first.
